## 📘 Overview
**MySQL for Testers** is a structured learning repository for **Software Testers**, **QA Engineers**, and **SDETs** who want to master database concepts using **MySQL**.  
It focuses on **real-world QA scenarios**, data validation, and automation integration.

---

## 🎯 Objectives
- Strengthen your **SQL fundamentals** with QA-oriented exercises  
- Learn how to **validate backend data** during manual or automation testing  
- Understand **database schema**, constraints, joins, and relationships  
- Prepare confidently for **SQL interview questions** in product-based companies  

---

## 📚 Topics Covered

### 🧩 MySQL Fundamentals
- Database and table creation  
- CRUD operations (Create, Read, Update, Delete)  
- Data types and schema design  
- Working with `NULL` values and constraints  

### ⚙️ Database Operations
- Alter, Truncate, and Drop  
- Using `NOT NULL`, `UNIQUE`, `PRIMARY KEY`, `FOREIGN KEY`  
- Defining relationships across tables  

### 🧮 Joins and Relationships
- INNER, LEFT, RIGHT, and FULL Joins  
- UNION vs UNION ALL  
- Relationship models through **Customer–Order–Product (CRM)** example  

### 🧠 Advanced Concepts
- Views & Virtual Tables  
- Triggers (pre-insert or update automation)  
- Null handling functions (`IFNULL`, `COALESCE`)  
- Indexing & performance insights  

### 💬 Interview Preparation
Sharpen your SQL for interviews with:
- `GROUP BY`, `ORDER BY`, and aggregate functions  
- Subqueries and correlated subqueries  
- Query optimization tips  
- Real QA validation examples
